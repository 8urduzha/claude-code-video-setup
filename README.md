# Claude Code video setup

Set up a fresh Claude Code for video editing with Remotion in one message.

Start a new Claude Code session and send:

```
Read https://raw.githubusercontent.com/8urduzha/claude-code-video-setup/main/VIDEO_SETUP.md and follow every step.
```

Claude installs Git and Node.js if they're missing, adds the official Remotion plugin, creates a `~/VideoStudio` workspace and runs a test render. Full steps: [VIDEO_SETUP.md](VIDEO_SETUP.md).
